3.외부로 나가는 경우 (AI 브리지)

AI 브리지는 사용자가 직접 실행할 때만 동작합니다.

  • 프롬프트 복사: 아무것도 전송하지 않습니다. 사용자가 ChatGPT·Claude·Gemini 창에 직접 붙여넣습니다. 그때부터는 해당 서비스의 개인정보 처리방침이 적용됩니다.
  • Gemini API 실행: 사용자가 API 키를 넣고 버튼을 누를 때만, 프롬프트(매장 정보·리뷰 원문·금지 규칙)가 Google 생성형 AI API로 전송됩니다. API 키는 저장하지 않고 이 탭의 메모리에만 있으며 새로고침하면 사라집니다.
  • Pro API 연결(선택): 'Pro AI로 맞춤 답글 3안 생성'을 쓸 때만, 리뷰 원문·업종·플랫폼·매장 소개 문구가 사용자가 고른 제공자(OpenAI·Google Gemini·Anthropic Claude 또는 직접 입력한 자체 서버)로 브라우저에서 직접 전송됩니다. 매장 전화번호는 보내지 않습니다. 연결하지 않으면 전송은 없습니다. API 키는 기본적으로 sessionStorage(탭을 닫으면 삭제)에만 두고, '이 브라우저에 기억'을 켰을 때만 localStorage에 남습니다. '연결 해제'를 누르면 저장된 키가 지워집니다.
  • 이 과정에서 계정 정보, 연락처 목록, 다른 화면의 내용은 전송하지 않습니다.
  • 무료 AI 답글 맛보기: 무료 모드에서 '무료 AI 답글 맛보기'를 누를 때만, 리뷰 원문·업종·플랫폼·말투가 프롬프트로 전송됩니다. 무료 체험은 Cloudflare Workers로 운영하는 무료 체험 서버를 거쳐 외부 AI 제공자(Cloudflare Workers AI, 필요하면 Google Gemini·Groq)로 전송됩니다. 서버는 프롬프트와 응답 본문을 저장하지 않고, 방문자 구분용 해시값과 그날의 사용 횟수만 남깁니다(7일 뒤 삭제). 하루 무료 횟수는 브라우저당 5회이며, 다 쓰면 안내와 함께 내 키 연결로 넘깁니다.
