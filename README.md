# 사장님 리뷰 답글 스튜디오

동네 자영업자(음식점·카페, 병원·치과·한의원, 미용실·네일, 학원·공부방, 숙박·펜션, 배달·스마트스토어)가
리뷰에 **사장님 말투로** 답글을 다는 일을 돕는 무서버 정적 웹앱입니다.

리뷰를 붙여넣으면 별점·포인트·감정을 읽고, 업종 6종 × 플랫폼 4종 × 상황 6종 × 말투 3종에 맞춰
답글 후보 3개를 만듭니다. 만든 문장은 **AI 티·법 위험·개인정보·책임 확답** 점검기를 다시 통과합니다.

- 라이브(예정): `https://marcj81.github.io/review-reply-studio/`
- 서버·DB·회원가입·결제 없음. 무료 모드에서는 입력한 내용이 브라우저 밖으로 나가지 않습니다.
- **Pro AI 연결(선택)**: 헤더의 `무료 모드 · API 연결` 배지에서 OpenAI·Gemini·Claude·자체 서버를 연결하면, 답글 작성 탭의 **✨ Pro AI로 맞춤 답글 3안 생성**이 리뷰 문맥·업종·법규 회피를 지켜 답글 3안을 쓰고, 기존 점검기를 다시 통과시킵니다. 기존 무료 `답글 3개 만들기`는 그대로 남습니다. 매장 전화번호는 전송하지 않으며, 키는 기본 `sessionStorage`입니다. 엔진: `engines/pro-api-connector.js` · `engines/pro-studio.js`
- 빌드 없음. `index.html`을 열면 바로 동작합니다.

## 1. 왜 만들었나

리뷰 답글은 대부분 세 가지 중 하나가 됩니다.

1. **안 다는 것** — 별점이 깎이고, 다음 손님이 "사장님이 답을 안 하네"라고 읽습니다.
2. **복붙한 자동응답** — "소중한 후기 감사합니다. 앞으로도 최선을 다하겠습니다." 손님은 읽지 않습니다.
3. **감정이 섞인 반박** — 컴플레인에 억울함을 먼저 쓰면 확산됩니다.

이 앱은 네 번째를 노립니다. **손님이 쓴 단어를 하나 짚어 주고, 그 가게가 실제로 하는 일을 한 줄 넣고,
위험한 표현은 빼는 답글.** AI가 문장을 새로 창작하는 대신, 사람이 쓴 문장 자산을 상황에 맞게 조립하고
점검합니다. 그래서 같은 리뷰에도 말투와 플랫폼에 따라 다른 답글이 나옵니다.

## 2. 화면 5개

| 탭 | 하는 일 |
| --- | --- |
| **답글 작성** | 리뷰 1개 → 답글 3안. 상황 자동 판별, 말투 3종 비교, 카드에서 바로 수정·복사 |
| **일괄 답글** | 리뷰 여러 개 붙여넣기 → 자동 분류 → 전체 답글 → 개별 복사·TXT·CSV |
| **신고 소명서** | 허위·악성 리뷰의 게시 중단 요청 사유서 초안 + 400자 요약 + 준비물 체크리스트 |
| **AI 브리지** | 지금 리뷰·매장 정보·금지 규칙을 프롬프트로 묶어 ChatGPT·Claude·Gemini에 전달 |
| **매장 설정** | 가게 이름·시그니처·주차·문의 번호·영업시간·한 줄 소개·재방문 혜택 저장 |

### 답글 작성

- 리뷰를 붙여넣으면 `★5 · 5점 칭찬 · 포인트: 친절, 맛`처럼 읽은 결과를 보여 줍니다.
- 상황은 자동으로 잡히고, 필요하면 칩으로 바꿉니다.
  - **5점 칭찬 / 사진·영수증 / 3~4점 아쉬움 / 1~2점 컴플레인 / 단골 / 예약·노쇼·휴무 공지**
- 말투 3종: **따뜻한 동네 사장님(해요체) · 정중하고 깔끔한 전문샵(합니다체) · 친근한 MZ 매장**.
  `3말투 비교`를 켜면 같은 리뷰로 세 목소리를 나란히 만듭니다.
- 카드마다 100점 만점 점수, 등급, 글자 수, **AI 티 고치기** 버튼이 있습니다.
- `다른 표현`을 누를 때마다 같은 리뷰로 다른 문장 조합을 만듭니다(같은 입력·같은 순서는 항상 같은 결과).
- `전체 복사`는 `[가게명] 리뷰 답글 3안` 형식으로 번호를 붙여 복사합니다.

### 일괄 답글

붙여넣은 글을 다음 순서로 나눕니다.

1. `---`, `===`, `***` 구분선
2. 빈 줄
3. `1.`, `2.` 번호 목록
4. `★★★★★`, `별점 4`로 시작하는 줄

각 리뷰의 별점을 읽어 상황을 자동 지정하고, 항목별로 상황을 바꿀 수 있습니다.
`전체 답글 만들기` 후에는 개별 복사·전체 복사·TXT·CSV(엑셀 호환, BOM 포함)로 내보냅니다.

### 신고 소명서

플랫폼 신고 창에 붙일 수 있는 형식으로 7개 절을 만듭니다.

```
1. 신청인 정보   2. 대상 리뷰   3. 위반 사유 및 근거   4. 사실관계
5. 확인 가능한 자료   6. 요청 사항   7. 확인
```

- 위반 유형 7가지: 허위·사실과 다른 내용 / 실제 이용하지 않은 리뷰 / 욕설·비방 / 개인정보 노출 /
  광고·홍보성 리뷰 / 진료·시술 관련 허위 / 협박·금전 요구
- 작성자 이름은 `가**님`처럼 가려서 넣습니다.
- 신고 폼용 **400자 요약**과 **준비물 체크리스트**를 함께 만듭니다.
- 법 조항은 **참고용**으로 표시합니다. 최종 판단은 플랫폼과 담당자에게 있습니다.

### AI 브리지

- 프롬프트에는 매장 정보, 리뷰 원문, 읽힌 포인트, 플랫폼 길이, 말투, 금지 규칙이 들어갑니다.
- `프롬프트 복사` 후 ChatGPT·Claude·Gemini 창에 붙여넣으면 됩니다.
- 무료 Gemini API 키가 있으면 앱에서 바로 받을 수도 있습니다.
  **키는 저장하지 않고 이 탭의 메모리에만** 두며, 새로고침하면 사라집니다.
- AI가 준 답글을 붙여넣으면 이 앱의 점검기를 다시 통과시켜 카드로 가져옵니다.

### 매장 설정

답글에 그대로 들어가는 정보입니다. **실제로 하는 것만** 적으세요.

| 항목 | 답글에서 하는 일 |
| --- | --- |
| 가게 이름 | 첫 문장과 마무리 |
| 시그니처 메뉴·시술 | 다음 방문의 이유 (한 번만) |
| 우리 가게 한 줄 | 가장 덜 자동응답처럼 보이는 지점 |
| 문의 번호 | 컴플레인 답글의 직접 연락 안내 |
| 주차 | 리뷰에 주차 이야기가 나올 때 |
| 재방문 혜택 | 단골 답글에만. 병원·배달 플랫폼은 제외 |

저장은 `localStorage` 키 `review-reply-studio:v1` 하나만 씁니다.

## 3. 점검기는 무엇을 보나

만든 답글(또는 직접 고친 답글)은 320ms 뒤 자동으로 다시 점검됩니다.

### AI 티 20종

`소중한`, `귀중한`, `앞으로도`, `최선을 다하겠습니다`, `더 나은 서비스로 보답`, `정성을 다해`,
`다양한`, `만족스러운`, `방문해 주셔서 감사합니다`, `바랍니다`, `고객님`, `진심으로 감사드립니다`,
`너그러운 양해`, `많은 관심 부탁드립니다`, `즐거운 하루 되세요`, `항상`, `~을 통해`, `되어집니다`,
`그것은`, `감사드립니다` …

각 표현에는 이유와 교정안이 붙습니다. `AI 티 고치기`는 **문법·군더더기만 안전하게** 바꾸고,
사실을 새로 만들지 않습니다. 카피 심리 엔진(`engines/copy-psych-engine.js`)의 번역체·공급자 중심
탐지도 함께 씁니다.

### 법·정책 위험

| 범위 | 예 |
| --- | --- |
| 공통 | `최고`, `1위`, `유일`, `100%`, `무조건`, `보장합니다` (표시광고법 제3조) |
| 병원 | `완치`, `치료 효과`, `부작용 없음` (의료법 제56조) · `할인`, `무료`, `사은품`, `소개비` (의료법 제27조③) |
| 학원 | `성적 보장`, `합격 보장`, `1등 보장` |
| 뷰티 | `영구`, `재생 보장`, `부작용 전혀` |

병원 업종은 **재방문 혜택을 답글에 넣지 않습니다.** 매장 설정에 혜택이 있어도 마찬가지입니다.
배달 플랫폼(배민·쿠팡이츠)은 주차·매장 방문 유도 문구를 넣지 않습니다.

### 책임·개인정보·태도

- **책임 확답**: `환불해 드리겠습니다`, `보상하겠습니다`, `책임지겠습니다` — 공개 답글에서는 확인 후 안내로.
- **개인정보**: 다른 전화번호, 주민번호 형태, 이메일, 계좌·카드 표현. `010-0000-0000` 같은 자리표시는 통과.
- **방어적 표현**: `억울`, `오해하신`, `그럴 리가`, `악의적`, `법적 조치`.
- **형식**: 플랫폼 권장 길이, 이모지 2개 이상, `!!`, 같은 문장 반복.
- **구체성**: 어느 가게에나 붙일 수 있는 문장만 있으면 "리뷰를 안 읽은 느낌"으로 감점.

점수는 100에서 유형별 상한을 두고 깎습니다(법 39, 개인정보 30, AI 티 24, 책임 20, 방어 16, 길이 7, 형식 8, 구체성 8).
등급: **A 90+ / B 80+ / C 70+ / D 그 미만.**

```bash

/workspace/scratch/node-v22.11.0-linux-x64/bin/node test.js

# 실제 브라우저 검증 (1440×900 · 390×844)
python3 uitest.py
```

`test.js`는 6×4×6×3 = **432개 조합 × 3안 = 1,296개 답글**을 만들어
빈 문장·남은 자리표시·중복·길이·법 위험·개인정보·점수를 전수 검사하고,

- 데스크톱·모바일 **가로 넘침 0**
- 예시 리뷰 → 답글 3장 생성, 복사, 수정 후 재점검, AI 티 교정

- Gemini 키 없이 실행 시 안내 문구(외부 요청 없음)
- localStorage 저장 후 새로고침 유지, 다크 모드, 푸터 개인정보 링크 200
- `preview-desktop.png` · `preview-mobile.png` 저장

## 8. 한계와 주의

- 답글은 **문장 자산 조합**입니다. AI가 리뷰의 맥락을 깊게 이해해 새로 쓰는 것은 아닙니다.
  그래서 리뷰에 없는 사실을 만들지 않는 대신, 아주 특수한 상황은 문장이 조금 일반적으로 보일 수 있습니다.
- `우리 가게 한 줄`에 적은 내용은 **사실이어야 합니다.** 그대로 답글에 들어갑니다.
- 법 조항과 위험 표현 기준은 참고용입니다. 업종·지역·플랫폼 정책에 따라 달라질 수 있습니다.
- 병원 답글은 치료 효과·환자 유인 표현을 자동으로 빼지만, 최종 게시 판단은 원장님 몫입니다.
- 소명서는 플랫폼이 요구하는 형식과 다를 수 있습니다. 붙여넣은 뒤 플랫폼 양식에 맞게 다듬으세요.
- Gemini API 결과의 정확성은 모델에 달려 있습니다. 가져온 답글도 점검기를 통과시키지만 사실 확인은 필요합니다.

## 9. 바꿔 쓰는 법

- **문장 추가**: `data.js`의 `BANKS`, `SIGNATURE_LINES`, `FIX_LINES`, `ASPECT_FIX`, `NOTICE_LINES`.
- **업종 추가**: `INDUSTRIES`에 항목을 넣고, 필요하면 `SIGNATURE_LINES`·`FIX_LINES`에 같은 id를 추가합니다.
  `aspects`에 넣은 포인트 순서가 문장 선택에 쓰입니다.

- **플랫폼 길이**: `PLATFORMS[].range`를 바꾸면 생성·점검·안내가 함께 바뀝니다.
